APK BANANE KE STEPS (coding nahi chahiye)
1. github.com par free account banao.
2. Top right "+" > New repository. Naam: sellerhub. "Create repository" dabao.
3. "uploading an existing file" link dabao. Is zip ko phone/PC par unzip karo, andar ki saari files aur folders drag karke upload karo. Commit changes dabao.
   (Agar .github folder upload na ho: Add file > Create new file, naam me  .github/workflows/build.yml  likho aur build.yml ka text paste karo.)
4. Upar "Actions" tab kholo. "Build APK" chalega (3-5 minute). Green tick aane tak ruko.
5. Us run par click karo > neeche Artifacts > "SellerHub-APK" download karo > zip kholo > app-debug.apk.
6. Phone me apk kholo, "Install from unknown sources" allow karo, install karo.
Error aaye to uska screenshot/text mujhe bhej do.
